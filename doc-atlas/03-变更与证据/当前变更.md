# 当前变更

## 2026-08-20：插件运行资产改为构建生成

- 选择方案 B：开发仓库不直接运行 Skill，`assets/` 只保留运行资产白名单。
- `templates/`、`schemas/`、`scripts/`、`rules/`、`operations/` 和 `compatibility/json` 为唯一源码。
