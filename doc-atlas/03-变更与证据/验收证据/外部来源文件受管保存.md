# 外部来源文件受管保存验收

## 范围

本证据记录 0.10.0 外部来源暂存箱、受管保存操作、自动验证、真实 Codex 行为和插件发布结果。Claude CLI 真实验收按用户要求未运行，不在本次通过结论范围内。

## 实现结果

- 初始化知识库包含 `Clippings/` 暂存箱和 `05-知识治理/来源资料/` 受管目录。
- `context-atlas-ingest` 只读清点每个普通文件，并逐项标记为可保存、重复或阻塞。
- `context-atlas-add` 仅在 Proposal 修订号与用户确认摘要完全一致时调用内置保存操作。
- 合格文件按内容摘要获得稳定来源身份，保存受管副本并生成来源登记卡。
- 保存副本摘要一致且知识库验证通过后才删除暂存原件；异常时回滚新增目标并保留原件。
- 重复文件复用稳定来源身份；阻塞文件留在暂存箱。
- 符号链接、可执行或不支持格式、超过 20 MiB 以及疑似包含秘密赋值的文本被阻塞。
- `Clippings/` 不属于正式知识校验、导航、影响分析、健康检查或迁移发现范围；保存来源也不表示批准其中的业务内容。

设计提交为 `93320e3`，实现提交为 `a7c1e0a`，验收契约结构修正提交为 `03dea18`。
