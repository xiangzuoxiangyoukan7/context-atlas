# 项目概述

## 项目定位

Context Atlas（脉络地图）是一套供 AI Agent 使用的项目知识库能力。当前用户支持宿主为 Codex、Claude Code 和 Qoder；它们共享工具无关的知识模型、模板、Schema、检查器和可安装插件，使项目知识能够初始化、维护、版本化和追溯。Trae 适配保留为内部候选，不属于当前用户支持范围。

## 解决的问题

AI Agent 在不同项目中需要反复理解项目定位、功能、设计和验收依据。缺少统一知识入口时，Agent 容易使用过期文档、把推测当作事实，或形成缺少来源和验收依据的结论。

## 面向对象

- 使用 AI Agent 理解和维护项目知识的项目成员。
- 为 Codex、Claude Code 和 Qoder 提供知识库能力的插件维护者。
- 需要跨 Agent 复用同一套项目事实、约束和证据的团队。

## 长期职责

- 提供工具无关的知识模型、目录规范、模板和 Schema。
- 提供知识采集、确认、冲突、更新、关系、影响和归档规则。
- 提供项目级安装的 Agent 插件及无 Skill 时的最低兼容入口。
- 提供确定性的结构、状态、链接、版本和追溯检查。
- 提供同一结构下的单技术栈和多技术栈示例。

## 明确不负责

- 不调用、托管或绑定任何大模型。
- 根据当前支持的 Agent 选择并受控补充项目入口文件：Codex、Qoder 使用 `AGENTS.md`，Claude Code 使用 `CLAUDE.md`；只维护 Context Atlas 标记区块，不覆盖项目原有内容。
- 不决定日常开发任务能否执行，也不把知识库维护变成开发门禁。
- 不替项目责任人批准需求、设计或验收结果。
- 不提供业务代码生成、编译、部署、Web 管理界面或中央知识服务。

## 当前阶段

核心协议、模板、Schema、检查器和可安装 Skill 已进入实现；跨 Agent 最终验收由功能内验收场景和[验收证据](../03-变更与证据/验收证据/README.md)追踪。
