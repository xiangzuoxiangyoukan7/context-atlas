# 项目边界

## 包含

- 工具无关的项目知识库模型、目录规范、模板和 Schema。
- AI 知识采集、候选、确认、冲突、更新和归档协议。
- 可安装的 Agent Skill 及不支持 Skill 时的通用协议入口。
- 功能、架构、契约、数据库、原型、外部依赖、任务、ADR、验收和证据的统一表达。
- Java、Python 可选 Profile 及混合使用规则。
- 结构、状态、链接、版本和追溯关系检查器。
- 通用、Java、Python、Java+Python 示例。

## 不包含

- 独立的面向用户知识库 CLI。
- 调用、托管或绑定任何大模型。
- 为目标项目生成或维护 `AGENTS.md`、`CLAUDE.md` 等工具专属文件。
- 规定 Agent 如何执行代码计划或替用户完成业务验收。
- 自动批准从代码、旧文档或模型推断出的内容。
- 业务代码生成、编译、部署或自动修复。
- 前端专属 Profile 的第一阶段实现和验收。
- Web 管理界面、远程服务、中央数据库和多用户权限系统。

## 不可逾越边界

任何 Profile 不得修改核心状态流转、权威来源、验收结果枚举和证据追溯规则。AI 推测不得直接写成批准事实；冲突不得由 AI 自行裁决。

## 责任边界

- 本项目负责协议、模板、Schema、示例、Skill 和检查器。
- Agent 负责调研项目、向用户提问、组织候选知识和执行文件操作。
- 项目责任人负责确认目标、范围、设计和验收标准的内容正确性。
- 知识库保存确认结果和来源，但不声称能够证明确认者身份。
