# ADR-009：外部来源文件受管保存

## 决策

- `Clippings/` 是外部文件临时暂存箱，待处理内容不参与正式知识解析。
- 每个暂存文件必须得到 `saved`、`duplicate` 或 `blocked` 结果，不能静默忽略。
- `ingest` 只读生成清单、摘要、安全检查、去重与目标计划；放入暂存箱不等于批准内容。
- 确认维护 Proposal 后，合格文件移动到 `05-知识治理/来源资料/files/<source-id>/`，并建立正式来源登记卡。
- 执行器先复制、校验摘要和目标范围，再提交目标；只有验证成功才删除暂存原件。失败时保留原件并回滚不完整目标。
- 保存来源证据不代表批准其中的需求、设计或结论。
