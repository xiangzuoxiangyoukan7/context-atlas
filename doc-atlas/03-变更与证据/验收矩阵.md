# 验收矩阵

KB-AC-11～18 用于知识库重新基线化，KB-AC-19～22 用于实现计划验收，KB-AC-23～43 用于阶段能力验收；F01～F05 记录当前产品验收。

历史跨 Agent 验收 `KB-AC-27`～`KB-AC-29` 继续由[跨 Agent 执行一致性与 Claude Code 验收](./验收证据/跨Agent执行一致性与Claude验收.md)跟踪，2026-08-23 Claude Code 2.1.241 复验后仍为 `partial`；它们不是当前 F01～F05 矩阵声明，不重复添加为现行表格行。

当前用户支持宿主限定为 Codex、Claude Code 和 Qoder。Qoder 的构建包、共享身份、运行资产和安装路径静态检查已经通过，真实 Agent 场景由用户继续验证，在证据闭环前不计入当前 F01～F05 的正式通过项。Trae 适配保留为内部候选，不属于当前用户支持或三平台验收范围；既有构建代码和历史证据继续保留。
