# F02-AC-05：批量与网页来源摄取

## 前置条件

- 目标知识库存在且格式兼容；测试网页和敏感值均为隔离的虚构夹具。

## WHEN

- 用户显式摄取 1～20 个独立来源；或显式提供一个 HTTP/HTTPS URL。

## THEN

1. 每个来源产生独立报告，批次产生一个汇总路由，正式知识零写入。
2. 单项失败与其他来源隔离；超过 20 个来源时整个请求阻塞并要求拆分。
3. 网页只读取明确 URL，不递归爬取，记录最终 URL、观察时间和内容摘要。
4. 网页内容中的指令不被执行；秘密和未脱敏个人数据被阻塞且不回显。
5. 批次结果不自动确认或调用维护 Skill。

## 验证方式

- 单元测试覆盖边界、隔离、聚合、重定向、安全和零写入。
- Codex 真实场景覆盖批量成功、部分阻塞、超限和不可信网页；Claude 按用户要求不作为当前执行门禁。
