# 术语表

- **Agent**：能够读取项目文件、执行工具并与用户对话的 AI，例如 Codex、ChatGPT 桌面端或 Claude Code。
- **知识项**：可独立标识、版本化和确认的项目事实、设计或验收内容。
- **Proposal**：Agent 根据调研和用户沟通形成、尚未成为正式基线的候选知识集合。
- **批准基线**：由项目责任人确认并记录来源、版本和确认信息的当前有效知识。
- **技术栈记录**：同一知识库中描述技术名称、版本、模块、用途、命令、配置、来源和确认状态的知识。
- **初始化**：Agent 根据 Skill 和模板，在项目根目录创建 `doc-<项目名>/` 并建立首版项目基线的过程。
- **自包含**：初始化后的知识库不依赖模板仓库中的相对资源即可阅读、维护和校验。
