# TASK-KB-002：项目知识库重新基线化

## 背景

旧版知识库只验收了概念骨架和基础检查器，没有清楚说明用户如何通过 Agent 初始化知识库，也缺少完整初始化产物、数据库、原型、外部依赖、可组合 Profile 和真实可用性验收。

## 范围

- 重新定义项目目标、产品形态、能力和边界。
- 确认 Agent 原生、无独立用户 CLI 的架构。
- 确认本项目不生成或维护工具专属 Agent 入口文件。
- 定义初始化产物、知识采集、Proposal、确认、冲突和版本协议。
- 将 Profile 调整为可选、可组合，第一阶段只维护 Java 和 Python。
- 建立新的功能卡、ADR、当前状态和验收标准。
- 将仍需要的规则吸收到现行基线，删除不再需要的旧任务和旧验收报告。

## 排除

- 不实现 Skill、模板、Schema、Profile、样例或检查器。
- 不编写产品实现计划。
- 不声明第一阶段产品能力完成。

## 完成条件

KB-AC-11～18 全部通过，项目责任人完成知识库基线评审。完成后才能创建产品实现任务包和实施计划。

## 完成记录

项目责任人于 2026-08-10 明确确认新知识库基线。验证证据见 [KB-AC-11～18 新基线验收报告](../验收证据/KB-AC-11-18-新基线验收报告.md)。
