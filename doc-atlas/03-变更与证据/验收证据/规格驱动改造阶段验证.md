## 已实现内容

- 新增 `approval_status`、`lifecycle_status`、`spec_readiness` 和阻塞问题约束。
- 新增 `acceptance_contract`、`specification_change` 和 `specification_delta` Schema。
- 支持 `ADDED`、`MODIFIED`、`REMOVED`、`RENAMED` 和 `SUPERSEDED` Delta 检查。
- 检查器支持 `all`、`structure`、`spec` 和 `readiness` 层级。
- `context-atlas-review` 保持只读，不直接修改、批准或迁移正式知识。
- OpenSpec 与 Spec Kit 适配器只输出候选映射和来源路径，并显式报告 `writes_performed: false`。
- Codex 与 Claude 共用七个 Skills，构建产物由统一资产清单生成。

- `context-atlas-review`、OpenSpec 适配器和 Spec Kit 适配器的跨 Agent 行为验收。
