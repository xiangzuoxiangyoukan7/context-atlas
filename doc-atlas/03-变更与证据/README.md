# 变更与证据

这里记录知识库已知的变化、验收声明和实际证据，不保存长期产品定义、技术基线或开发任务计划。

- [变更](./变更/README.md)：保存具有稳定身份的规格变化
- [验收证据](./验收证据/README.md)：实际执行结果、证据与版本；验收视图由功能内场景和证据动态生成
- `验收证据/`：保存可定位的实际验证记录
- `影响记录/`：仅在破坏性变化、迁移或审计需要时按需创建；日常影响动态查询
- `待确认知识/`：仅在用户明确要求记录候选时按需创建

Issue、OpenSpec、Superpowers 或其他工具负责开发任务与计划。本目录不保存任务拆分、修改许可或调度状态。历史任务已归档到 `90-历史归档/实施任务包/`，不能覆盖现行功能、架构或验收状态。
