# 初始化产物契约

## 命名

Agent 在项目根目录初始化知识库。默认项目名取当前目录名，知识库目录为 `doc-<项目名>/`；用户可以明确覆盖项目名。

## 必需结构

初始化结果必须包含根 README、机器入口、项目总览、功能基线、架构与契约、实施与验收、ADR、开发指南和历史归档。数据库、原型、外部依赖、任务包和验收证据必须具有明确目录。

## 安全规则

- 目标目录已存在时不得覆盖，必须读取现有知识库并进入更新流程。
- 初始化前必须展示目录、已发现事实、假设和待确认项。
- 初始化结果不得包含 `AGENTS.md`、`CLAUDE.md` 等 Agent 专属文件。
- 初始化结果必须自包含，不得引用模板仓库中的私有相对路径。

## Profile

Profile 可不选，也可同时选择多个。Java 和 Python 属于第一阶段；前端不属于当前验收范围。
