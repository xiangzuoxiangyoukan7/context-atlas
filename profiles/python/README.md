# Python Profile

`profile_id: python.v1`。适用于 FastAPI、Django、Flask 和 Python 工具项目。

## 增加字段

- `python_version`
- `environment_manager`
- `package_manager`
- `framework`
- `test_command`
- `type_check_command`

## 增加验收

解释器和环境可复现、依赖锁定、pytest/类型检查边界明确、服务入口和配置来源可追溯、秘密不进入仓库。

## 边界

本 profile 不修改核心功能状态、验收结果枚举或 AI 权威来源规则。
