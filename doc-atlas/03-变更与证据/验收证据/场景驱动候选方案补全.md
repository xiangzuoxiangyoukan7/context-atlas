## 验收场景

1. 用户提出建立业务表并说明保存内容和使用方式，但没有逐字段指定 SQL 数据类型。
2. Agent 读取数据库产品、关联功能、接口、现有表结构和仓库惯例。
3. Agent 提供字段、类型、可空性、默认值、值域、索引和关系的推荐候选，并逐项说明依据。
4. 无法确定唯一选择时，Agent 提供二至三个具体选项、影响和推荐项，而不是只报告“类型缺失”。
5. 所有推导内容保持 `ai_inference` 和 `proposed`；正式知识仍须由用户确认精确 Proposal 修订后写入。
