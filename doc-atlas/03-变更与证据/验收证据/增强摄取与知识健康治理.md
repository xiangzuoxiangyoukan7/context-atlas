# 增强摄取与知识健康治理验收

## 范围

本证据记录 0.8.0 增强摄取、显式摄取历史和只读知识健康检查的实现、自动验证、真实 Codex 行为及插件发布结果。Claude CLI 真实验收按用户要求未运行，不在本次通过结论范围内。

## 实现结果

- `context-atlas-ingest` 支持每批最多 20 个独立来源，逐来源隔离结果并生成批次汇总路由。
- 单 URL 网页读取限制协议、地址、内容类型和 1 MiB 大小；网页正文始终作为不可信数据处理。
- 摄取历史默认关闭；显式保存时仅写入 `.context-atlas/ingest-history/`，执行脱敏并按 100 条、30 天清理。
- `context-atlas-review` 提供 `knowledge_health` 只读模式，报告重复身份、孤立项、断裂关系、陈旧项、未解决冲突、未验证来源和权威入口缺口。
- 超过 20 个来源时返回完整阻塞报告，不分析任一来源，也不修改正式知识。

实现与场景提交为 `5d726d9`、`96716b7`、`217c1ae`、`aada02e` 和 `ef349af`。
