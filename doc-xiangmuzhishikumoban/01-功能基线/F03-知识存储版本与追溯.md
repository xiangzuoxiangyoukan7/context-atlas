# F03：知识存储、版本与追溯

## 目标

使用 Markdown、受控 YAML 元数据和 Git 保存可阅读、可版本化、可追溯的项目知识。

## 规则

- 每个正式知识项具有唯一 ID、状态、版本、来源和更新时间。
- 批准内容必须记录确认信息。
- 新版本替代旧版本时，旧内容进入 `superseded` 或历史归档，不被静默删除。
- 功能、设计、任务、验收和证据形成可检查的引用链。

## 验收

- `F03-AC-01`：批准知识能够追溯到来源、确认信息和有效版本。
- `F03-AC-02`：更新不会静默覆盖历史，当前基线与历史版本能够明确区分。
