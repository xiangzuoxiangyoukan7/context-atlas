## Agent 可执行协议

Codex 与 Claude Code 读取同一 Skill 后使用同一个 `agent_kb_operation.py`：

```text
identify-contributor → capture
diagnose-format → migrate-propose → 用户确认同一修订号 → migrate-apply
```

所有命令返回 JSON 和明确退出码。身份报告只返回邮箱摘要；捕获结果只创建 `status: proposed`；迁移应用会重新计算当前提案，文件发生变化、存在未解析关系或确认号不一致时拒绝写入。
