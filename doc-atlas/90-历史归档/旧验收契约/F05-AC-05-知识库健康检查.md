# F05-AC-05：知识库健康检查

## 前置条件

- 目标知识库可读取，并提供健康黄金样例及七类独立反例。

## WHEN

- 用户显式运行知识库健康检查。

## THEN

1. 只读报告重复身份、孤立项、断裂关系、陈旧项、未解决冲突、未验证来源和权威入口缺口。
2. 可确定的结构问题为错误；时间阈值和业务语义问题为警告或 `review_required`。
3. 检查结果包含代码、路径、稳定 ID、原因和建议，不修改或批准知识。
4. 健康检查不把 `.context-atlas/ingest-history/` 当作正式事实来源。

## 验证方式

- 黄金样例通过；每类问题有独立反例。
- 运行前后正式知识文件摘要一致。
