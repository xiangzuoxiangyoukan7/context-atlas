# AI 知识采集协议

## 读取顺序

README → 本协议 → 与用户请求相关的需求、功能、契约、ADR 和验收项；存在关联变更集或任务包时再按需读取。

## Proposal

Agent 调研仓库和已有文档后，向用户展示：目标位置、发现事实及来源、推断、未知项、冲突、拟写文件、技术栈记录和验证方式。用户明确确认前不得把 Proposal 写成 `approved`。

## 写入规则

- 事实附来源；推断标记 `ai_inference`。
- 冲突保留至少两个来源，并指定需要谁裁决。
- 批准项记录确认人、确认时间和版本。
- 替代旧知识时保留确有审计价值的历史并建立双向引用。
- 密码、Token、私钥和未脱敏个人数据不得写入；配置只记录 `${ENV_VAR}` 形式。

Agent 完成后报告写入路径、记录的技术栈、检查结果、未解决项和下一步。不创建或维护 `AGENTS.md`、`CLAUDE.md`。

知识库不决定外部任务能否执行。任务可以来自用户、Superpowers、OpenSpec、Issue 系统或其他 Agent；Context Atlas 只在正式知识写入时执行提案、确认、来源、影响和验证规则。
