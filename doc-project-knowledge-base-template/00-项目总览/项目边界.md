# 项目边界

## 包含

- 项目知识库目录、模板、Schema、profile、检查器和 AI 上下文协议。
- 功能、架构、数据库、契约、ADR、任务和验收证据的统一表达。
- 多个 AI 工具的薄入口适配。

## 不包含

- 业务代码生成、编译、部署或自动修复。
- 规定 Claude Code、Codex 或其他 AI 工具内部如何执行计划或完成验收。
- 替代产品负责人、架构师或测试人员判断内容是否正确。
- 自动从源代码推断并批准需求或验收标准。
- 强制所有项目使用同一种语言、框架或云平台。

## 不可逾越边界

任何 profile 不得修改核心状态流转、权威来源、验收结果枚举和证据追溯规则。

## 责任边界

- 本项目负责知识的结构、版本、关联、入口和可检查性。
- 项目责任人负责确认目标、功能、架构、数据库、外部依赖和验收标准的内容正确性。
- AI 工具是知识库的消费者和适配器；不同工具可以分工，但不得改变知识库的权威来源、当前基线或验收结果。
