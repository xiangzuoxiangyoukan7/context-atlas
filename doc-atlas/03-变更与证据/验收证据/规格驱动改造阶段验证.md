## 已实现内容

- 新增 `approval_status`、`lifecycle_status`、`spec_readiness` 和阻塞问题约束。
- 新增 `acceptance_contract`、`specification_change` 和 `specification_delta` Schema。
- 支持 `ADDED`、`MODIFIED`、`REMOVED`、`RENAMED` 和 `SUPERSEDED` Delta 检查。
- 检查器支持 `all`、`structure`、`spec` 和 `readiness` 层级。
- 完整覆盖检查连接需求、功能、契约或模块、外部任务、验收契约和证据，并使用 `KB_COVERAGE_*` 问题代码报告断链。
- 格式 7 迁移同步模板、Schema、脚本、规则、操作和兼容声明，支持摘要漂移检查、原子替换、回滚和幂等保护。
- 提交 `0c18ee1` 补齐格式 7 迁移所需的变更模板、Delta 模板和验收契约模板；提交 `7a37403` 将本项目知识库升级到格式 7。
- `context-atlas-review` 保持只读，不直接修改、批准或迁移正式知识。
- OpenSpec 与 Spec Kit 适配器只输出候选映射和来源路径，并显式报告 `writes_performed: false`。
- `review_is_read_only`、`review_reports_blockers`、`openspec_mapping_is_read_only`、`spec_kit_mapping_is_read_only` 和 `external_status_is_not_approval` 在 Claude Code 2.1.237 与 Codex CLI 0.148.0 上均通过。
- Codex 与 Claude 共用七个 Skills，构建产物由统一资产清单生成。
