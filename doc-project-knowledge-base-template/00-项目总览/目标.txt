对于高频外部依赖的沉淀功能

不同模型的侧重点不同，比如 claude code 编写功能文档，codex执行，claude code 验收

本知识库的设计目标是为持续沉淀项目知识，功能设计，架构设计，数据库设计等相关内容，基于以上不变内容AI可以生成执行计划，执行完成之后可以根据验收标准进行相应验收；
不关系AI基于执行计划怎么做，不关注于AI怎么验收，更关注于提供精准的上下文；提供内容对不对，验收标准对不对
