## 质量与边界

记录包/模块边界、配置来源，以及 pytest、类型检查、lint 的真实命令。不得预设 FastAPI、Django、Flask、Poetry 或 uv。

## 验收补充

保存解释器、安装、测试、类型和 lint 的可复核证据。秘密值不得写入，只记录 `${ENV_VAR}` 形式的名称。
