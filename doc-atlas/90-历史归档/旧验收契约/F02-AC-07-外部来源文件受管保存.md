# F02-AC-07：外部来源文件受管保存

## 前置条件

- 目标知识库已初始化，`Clippings/` 暂存箱与内嵌受管来源操作可用。

## WHEN

- 用户把一个或多个外部文件放入 `Clippings/`，并显式请求摄取和保存。

## THEN

1. 每个文件恰好出现一次，结果为可保存、重复或阻塞；临时 Frontmatter 不破坏知识库检查。
2. 确认前不移动文件、不建立来源卡；确认后合格文件进入固定受管目录且摘要一致。
3. 目标和登记卡验证成功后才删除暂存原件；失败或阻塞文件保持不变。
4. 路径逃逸、符号链接、覆盖、可执行文件、超限和敏感内容被阻塞。
5. 保存来源不批准其中的业务知识。

## 验证方式

- 单元测试覆盖成功、重复、阻塞、部分批次、回滚、路径与覆盖边界。
- 真实 Codex 覆盖成功保存和阻塞保留；Claude 不作为当前执行门禁。
